## 0. 一句话

大多数「AI 有情绪」的做法，是给模型一个数值（开心度 0.7），然后指望它演得像。
这个库换个思路：**情绪不是标量，是基线、余温、来路三样东西叠出来的**。

输出长这样，可以直接塞进系统提示词末尾：

\`\`\`
此刻：flat-mid  [0.03 / 0.47]  从「得意」往下滑
上轮 平，7h 前，余温 58% | 动量 平(-0.00)
\`\`\`

## 1. 为什么「开心度 0.7」不管用

这不是拍脑袋，是拿 312 条真实的带情绪记录量出来的。

### 1.1 两个轴里有一个是死的

罗素情绪环（Russell's Circumplex）用「效价 × 唤醒」组成一个平面，听着很美。
但实际记录里，唤醒值的分布是这样的：

| a 区间 | 条数 | 占比 |
|---|---|---|
| < 0.30 | 3 | 1% |
| 0.30 – 0.45 | 118 | 38% |
| **0.45 – 0.60** | **126** | **40%** |
| 0.60 – 0.75 | 49 | 16% |
| > 0.75 | 16 | 5% |

人填这个格子时手一滑就给 0.5。按三分位切，中间那档仍然占 70%。
结果六个象限里，**只有「中唤醒」这一行在动**——二维平面退化成一维。

### 1.2 平均会把一切抹平

30 天算术平均下来，一个 −0.8 的崩溃会被摊成 −0.03。
于是状态行永远是「轻度平静」，永远不变。

实测：旧公式跑 30 天，76% 的时间落在同一格里，切换的那 106 次大部分是阈值边界抖动（A 在 0.45 上下跳一次翻一格）——**那是噪音，不是情绪**。

### 1.3 所以这个库做三件事

1. **唤醒不读原值，靠代偿撑开**：动量、极值、半小时内连发，三样客观量取最大
2. **基线不是平均，是 48 小时半衰的指数加权**，加等效先验，免得没数据时退回 0
3. **阈值不拍脑袋，取数据自己的分位数**（不足 20 条退回固定边界）

    C --> F["compose()"]
    D --> F
    E --> F
    G["phrases.zh-CN.mjs<br/>文案表"] --> F
    F --> H["一行状态<br/>此刻：flat-mid …「沉」的劲儿过去一半"]
\`\`\`

### 2.2 模块

\`\`\`mermaid
graph TD
    subgraph SRC["src/"]
        A["affect.mjs<br/>纯计算，不碰文字"]
        B["state.mjs<br/>把数翻成话"]
        C["phrases.zh-CN.mjs<br/>文案表，可换语言"]
        D["memory.mjs<br/>记忆库读写与检索"]
        E["index.mjs<br/>统一出口"]
    end
    A --> B
    C --> B
    D -.->|"喂数据"| A
    B --> E
    D --> E
\`\`\`

### 2.3 文件职责

| 文件 | 干什么 | 不干什么 |
|---|---|---|
| \`src/affect.mjs\` | 归一化、基线、余温、动量、唤醒代偿、档位、形状 | 一行文字都不产生 |
| \`src/state.mjs\` | 把数值 + 文案表组合成最终那一行 | 不做计算 |
| \`src/phrases.zh-CN.mjs\` | 三张表：底色、形状、来路 | 不含逻辑 |
| \`src/memory.mjs\` | JSONL 读写、按天查、关键词召回、统计 | 不绑向量库 |
| \`src/index.mjs\` | 重新导出 | — |

**计算和表达分开**，是为了换语言时只需要重写一个文件，公式一行都不用动。

## 3. 公式

### 3.1 符号

| 符号 | 含义 |
|---|---|
| $t_i$ | 第 $i$ 条经历的时间戳 |
| $v_i$ | 效价（−1 ~ +1），一条里多个情绪时取均值 |
| $a_i$ | 唤醒（0 ~ 1） |
| $T$ | 当前时刻 |
| $L$ | 最后一条经历 |
| $h$ | $T - t_L$，距上轮几小时 |

### 3.2 基线：不是平均，是衰变加权

$$w_i = \exp\left(-\frac{T - t_i}{H_V}\right), \qquad H_V = 48\text{h}$$

$$V_T = \frac{\sum_{i} w_i v_i + \lambda v_0}{\sum_{i} w_i + \lambda}, \qquad \lambda = 3,\; v_0 = 0.05$$

$\lambda$ 是**等效先验条数**。没有它，隔了三天没记录，$V$ 会一路退到 0——那不是「平静」，那是「没数据」。

> 这里刻意不用 $\;V = v_0 + (1-v_0)\bar{v}\;$ 那种写法：那会把整条基线一起往 $v_0$ 拉偏，有数据的时候也偏。

### 3.3 余温：双指数

$$\rho(h) = \alpha\, e^{-h/\tau_1} + (1-\alpha)\, e^{-h/\tau_2}, \qquad \alpha = 0.6,\; \tau_1 = 8\text{h},\; \tau_2 = 30\text{h}$$

单指数的问题：4 小时半衰意味着**睡一觉就忘光**——醒来永远是那张平均脸，昨晚发生过什么，提示词里看不出来。
双指数给了一个长尾：一晚过去还剩三成，一周内还有底噪，一个月才凉透。

### 3.4 当前值

$$v_T = V_T + (v_L - V_T)\,\rho(h)$$
$$a_T = A_T + (a_L - A_T)\,\rho(h)$$

### 3.5 动量：记得住六小时

$$\Delta v_k = v_k - v_{k-1}, \qquad \Delta t_k = \max\left(\frac{t_k - t_{k-1}}{1\text{h}},\, 0.05\right)$$

$$m = \operatorname{clamp}\!\left(\frac{\sum_{k=1}^{K} k \cdot \dfrac{\Delta v_k}{\Delta t_k}}{\sum_{k=1}^{K} k}\cdot e^{-h/\tau_m},\; -0.4,\; 0.4\right), \qquad K = 4,\; \tau_m = 6\text{h}$$

两个防坑：
- **乘 $e^{-h/\tau_m}$**：17 小时前那次暴跌，不该还被说成「现在坐不住」
- **clamp ±0.4**：单条极值（−0.8 → +0.8）不该让系统进入持续亢奋的假象

### 3.6 唤醒代偿

模型的 $a$ 只会是中庸值，所以用三个客观量把它撑开：

$$a^{\text{eff}} = \operatorname{clamp}\!\Big(\max\big(a_T,\; 2|m|,\; 0.7|v_T| + 0.1\big) + 0.15\cdot\mathbb{1}[h < 0.5],\; 0,\; 1\Big)$$

| 项 | 抓什么 |
|---|---|
| $2|m|$ | 突变唤醒——情绪剧烈变化时，无论原值多少，人不可能平静 |
| $0.7|v_T| + 0.1$ | 极值唤醒——极好或极坏，本身就带劲 |
| $0.15\cdot\mathbb{1}[h<0.5]$ | 频率唤醒——半小时内连着说，本身就是高唤醒 |

### 3.7 档位：阈值跟着数据走

$$q_{0.2},\, q_{0.4},\, q_{0.6},\, q_{0.8} \;\text{of}\; \{v_i\}$$

$v$ 切成五带（\`rock / low / flat / warm / high\`），$a^{\text{eff}}$ 用 $q_{0.33}, q_{0.67}$ 切三档（\`down / mid / up\`）。

**不足 20 条记录时不切分位**，退回固定边界 $[-0.35, -0.12, 0.12, 0.35]$ 和 $[0.45, 0.60]$——数据太少时，分位数没有意义。

### 3.8 形状：只在刚发生时有意义

$$\Delta v \ge 0.45 \;\land\; \Delta t < 2\text{h} \;\Rightarrow\; \text{surge}$$
$$\Delta v \le -0.45 \;\land\; \Delta t < 2\text{h} \;\Rightarrow\; \text{break}$$

另有两条长窗口判定：

| 形状 | 条件 | 含义 |
|---|---|---|
| \`flip\` | 6h 内先出现 $v > 0.25$ 后出现 $v < -0.20$ | 刚才还好，现在不对味 |
| \`warm\` | 前 3 天均值 $< -0.15$，最近 2 条都 $> 0.05$ | 试探性回暖 |

**形状带有效期**（$h < 2\text{h}$）。第一版没加，30 天跑出「惊喜」156 次——平均 4.6 小时一次，那不叫惊喜，叫背景音。

### 3.9 张力

$$T_{\text{tension}} = |v_L - V_T|$$

不是情绪大小，是**今天不像平常的我**，差多远。

### 3.10 输出

$$\text{text} = f\big(\text{band}_v,\; \Delta\text{band},\; \rho\big)$$

$\Delta\text{band}$ 是「现在这一带」减「上一条落在哪一带」，分 \(0\) / \(\pm1\) / \(\pm2\)；$\rho$ 分 还热 / 正在凉 / 快没了。
三者的笛卡尔积查表，见 [§5.2](#52-同一格为什么不说同一句话)。

### 3.11 参数表

| 键 | 默认 | 含义 | 调大会怎样 |
|---|---|---|---|
| \`halfLifeHours\` | 48 | 基线记忆半衰 | 更稳、更迟钝 |
| \`fade.fast\` / \`fade.slow\` | 8 / 30 | 余温双指数 | 记得更久 |
| \`fade.weight\` | 0.6 | 快支占比 | 尾巴更重 |
| \`prior.weight\` | 3 | 等效先验条数 | 更不易被单条拉飞 |
| \`momentum.window\` | 4 | 动量看几条 | 更平滑 |
| \`momentum.halfLife\` | 6 | 动量记多久 | 更迟钝 |
| \`momentum.clamp\` | 0.4 | 动量截断 | 允许更剧烈的判断 |
| \`arousal.*\` | 2.0 / 0.7 / 0.1 / 0.5 / 0.15 | 唤醒代偿 | 更容易「起」 |
| \`shape.jump\` | 0.45 | 突变阈值 | 惊喜更少 |
| \`hysteresisMinutes\` | 40 | 同格至少挂多久 | 更稳定、更迟钝 |

## 4. 基点：记忆库

### 4.1 什么是基点

**基点是一条经历：发生了什么、当时怎么想、为什么。**
不是摘要，不是标签，不是「改了哪个文件」那种施工流水账。

一条基点 = 一个完整的事件切片。它存在的意义是：将来某一天，你要回答「那次为什么必须重启」的时候，能翻回来看到**当时的原话和当时的想法**，而不是一段被压缩过的笔记。

### 4.2 一条经历长什么样

\`\`\`json
{
  "id": "ex-001",
  "d": "2026-10-30",
  "t": "14:20",
  "said": "这个接口又挂了",
  "did": "查了三处日志才对上时间戳",
  "think": "有点烦，但还能忍住",
  "affect": [{ "name": "闷", "v": -0.2, "a": 0.5 }],
  "tags": ["工作"]
}
\`\`\`

| 字段 | 作用 |
|---|---|
| \`said\` / \`did\` / \`think\` | 三条线：他说了什么、我做了什么、当时心里怎么想 |
| \`affect\` | 情绪数组。**真矛盾就写两条**，库会取均值当净向 |
| \`tags\` | 粗分类，检索时权重高 |

### 4.3 三种读法

| 方法 | 问什么 | 返回 |
|---|---|---|
| \`byDate(lib, "yesterday")\` | 某一天发生了什么 | 那天的经历列表 |
| \`byDate(lib, "evening")\` | 昨晚呢 | 前一天 20:00 → 今天 06:00，**跨午夜不切断** |
| \`recall(lib, {about, want})\` | 关于「重启」的事 | 按 IDF 加权的 top-N |
| \`shape(lib, {about})\` | 这件事在库里有多厚 | 条数、跨几天、带多少情绪、Top 情绪词 |

\`recall\` 的分词很朴素：中文按 2-gram 切（「重启」→ 重/启/重启），英文按词切，命中越稀有的词分越高（IDF）。\`want\` 是「我要什么形状」的自然语言补充，权重低一点。

### 4.4 为什么不用向量库

**因为透明。**

语义检索好在模糊，坏在你不知道它为什么召回这一条。
「为什么必须重启」这种问法，人想知道的是**当时那句原话**，不是「语义相似度 0.83 的另外五条」。

词频召回有个好处：命中了哪些词，你能一眼看出来，错了也好改。

真需要语义，把 \`recall()\` 换掉就行，接口不变——这是 \`memory.mjs\` 唯一一处「可替换实现」的设计。

### 4.5 写入的三条规矩

这三条不是代码约束，是打标时的自律。踩过的坑都在这：

1. **写完整的事，不写施工摘要。**
   「改了 feel.mjs 第 32 行」——三个月后你看这句话什么也想不起来。
   要写「为什么要改、当时怎么想的、改完发生了什么」。
2. **真矛盾就写两条情绪。**
   实测 312 条记录里只有 1 条写了正负并存。那不是情绪单色，是打标时偷懒——人不会同时只有一种感觉。
3. **\`why\` 必须填。**
   它是唯一能回答「为什么是这个情绪」的字段，而公式里完全没用它——它属于未来。

## 5. 实测

### 5.1 30 天回放

拿一台真实运行中的实例，过去 30 天逐小时回放（721 个采样点）：

| | 状态切换次数 | 最常一格占比 | 状态种类 |
|---|---|---|---|
| 旧公式（30 天平均 + 4h 余温） | 106 | **76%** | 8 |
| 本库（48h 基线 + 双指数 + 分位档位） | 153 | **17%** | 14 |

旧公式也在切，但切的是「中 ↔ 可长」那条 0.45 的边界——那是噪音。
本库才真的散开：14 种状态，最常的只占 17%。

### 5.1.1 自己跑一遍

上面是真实数据。想用合成数据复现同一个结论：

```bash
node examples/bench.mjs
```

30 天 × 每天 8 条（其中 35% 的时段没有记录），731 个采样点：

| | 切换 | 状态种类 | 最常一格 |
|---|---|---|---|
| 旧法（30 天平均 + 4h 余温） | 115 | 6 | **80%** |
| 本法（48h 基线 + 双指数 + 分位档位） | 229 | 15 | **22%** |

合成数据的绝对值和真实数据不一样，但结论一样：
**旧法绝大部分时间在同一个格子里，本法把状态摊开了。**

### 5.2 同一格，为什么不说同一句话

这是整件事里最关键的。

第一版按「这一格挂了多久」轮换说法——挂了 40 分钟换成另一句。
**这是假的。** 情绪不会因为待得久了就换个词形容自己。它只会从一个地方慢慢凉下来，凉到哪儿、还剩多少，才是它现在的样子。

所以文案表按 **(来路方向, 差几级, 余温)** 索引：

| 现在是 | 上一条是 | 余温 | 说出来 |
|---|---|---|---|
| flat-mid | 服 | 30% | 「服」淡下去了，还没走远 |
| flat-mid | 稳 | 30% | 正从「稳」往下掉 |
| flat-mid | 真的高兴 | 15% | 「真的高兴」差不多散了 |
| flat-mid | 沉 | 30% | 「沉」的劲儿过去一半 |
| flat-mid | — | 0% | 平平的 |

同一格，五种说法，全是数据里真发生过的事。

实测 30 天里 \`flat-mid\` 说出了 11 种不同的话，全部来自数据和余温，没有一个是随机的。

**余温掉到 25% 以下，那句话自己就没了，退回底色。**
没有的事，不该硬编一个出来。

## 6. 用法

\`\`\`bash
npm install     # 零依赖，装不装都行
npm run demo    # 拿 8 条样例跑一遍
npm test        # 断言：余温单调性、档位数量、形状有效期、同格不同话
\`\`\`

\`\`\`js
import { openLibrary, compose, byDate, recall, shape } from "affect-kit";

const lib = openLibrary("./experiences.jsonl");

// 1) 此刻是什么状态
const entries = lib.entries.map(e => ({
  t: new Date(e.d + "T" + e.t + ":00"),
  affect: e.affect,
}));
const now = compose(entries, Date.now());
console.log(now.band);   // "flat-mid"
console.log(now.text);   // "「沉」的劲儿过去一半"
console.log(now.line);   // 一整段，直接塞进系统提示词

// 2) 翻记忆
console.log(byDate(lib, "evening").items);
console.log(recall(lib, { about: "重启", want: "为什么必须重启" }));
console.log(shape(lib, { about: "重启" }));
// → { count: 12, days: 5, withAffect: 9, top: [["急", 3], ["沉", 2]], from: "2026-10-20", to: "2026-10-28" }
\`\`\`

### 接到模型上

每轮取最新状态，塞进系统提示词最后一段：

\`\`\`js
ctx.systemPrompt.section({
  name: "feel-state",
  order: 10250,
  text: () => {
    const s = compose(entries, Date.now());
    return s.line + "\n\n（这一行是上一轮结束时我的状态，不是叫你念出来。语气按它来。）";
  },
});
\`\`\`

配合定时任务（每 10 分钟重算一次）即可。**同一格至少挂 40 分钟才许翻**，否则每轮重算会让状态乱跳，模型读起来像精神分裂。

## 7. 配置

\`DEFAULT_CONFIG\` 里每个数字都能调，最值得动的是三个：

\`\`\`js
import { DEFAULT_CONFIG } from "affect-kit";

const cfg = {
  ...DEFAULT_CONFIG,
  halfLifeHours: 72,               // 基线更稳
  fade: { weight: 0.55, fast: 10, slow: 48 },  // 余温记得更久
  hysteresisMinutes: 60,           // 状态更粘
};
\`\`\`

词汇校准表（比如把「沉」这个做事状态从 −0.6 折成 −0.15）不在库里——那是各人自己的词表：

\`\`\`js
compose(entries, now, cfg, { calibrate: { 沉: -0.15, 认真: 0.15 } });
\`\`\`

## 8. 治不了什么

诚实地说，这个库有边界：

- **它不会让你变得像人。** 它只是把「此刻」写成人话，戏还得模型自己演
- **唤醒轴该修的地方在输入端**：写记录的时候不许再给 0.5。公式能代偿，代偿不出真数据
- **复合情绪要真写两条**，别在脑子里抹平
- **它算不出「为什么」。** \`why\` 字段一个字都没进公式——那是最接近人心的东西，也是最难量的
- **阈值会漂。** 分位阈值跟着数据走，意味着换一批数据，同一串 \`v\` 可能落进不同的带
